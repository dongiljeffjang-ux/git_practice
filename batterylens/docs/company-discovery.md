# 회사 목록 발견 패스 리포트 (2025~2026)

> 목적: `companies.yaml` 확정을 돕기 위해, 최근 배터리 밸류체인 뉴스·리서치에서 세그먼트별로 자주 등장하는 회사를 조사하고 초안 46개사와 대조한 **후보 리포트**. 확정안이 아니며, 발주자 판단으로 편입·제외를 정한다. 관점: 한국 양극재·음극재 소재사(포스코퓨처엠) 시장조사.

## 이 리포트로 내린 결정 (발주자 확정)

1. **명백한 누락 추가**: Reshine(삼원계 출하 1위), Brunp(중국 전구체·리사이클 최대사).
2. **비중국권 OEM 추가**: Honda, Nissan, Renault(Ampere).
3. **ESS 셀사 추가**: Hithium, REPT Battero (ESS를 조사 범위에 포함).
4. **제련 성격 제외**: 고려아연 본체·LS MnM·Glencore 제외, 켐코(전구체 JV)만 유지.
5. **데이터 모델 변경**: 수직겸업사를 위해 회사에 **밸류체인 세그먼트를 복수 태그** 허용.

→ 확정 목록은 PRD 부록 A(v1.4) 참조.

## 세그먼트별 대조 결과

분류: **잘 잡음**(초안에 있고 자주 언급) / **누락 후보**(자주 언급되나 초안에 없음) / **재검토**(초안에 있으나 언급 드묾·세그먼트 모호).

- 누락 후보: **AESC/Envision**(비중국권 셀 — 희소가치), **Hithium**(정치형 ESS 2위), **REPT Battero**(ESS 상위), **SVOLT**(코발트프리 NMX 소재 채택처)

### 5. 원료-전구체 (광산·제련 제외)
- 잘 잡음: CNGR, GEM, Huayou, 에코프로머티리얼즈
- 누락 후보: **Brunp(邦普, CATL 자회사 — 삼원계 전구체 누적 100만톤, 중국 리사이클 50.4%)** — 상류 최대 누락

- 재검토: 새빗켐·에코프로씨엔지(한국 도메스틱, 영문 빈도 낮으나 유지), Glencore(제련 성격 → 제외 가능)

## 수직겸업(복수 세그먼트) 회사
- **Brunp·GEM·Huayou·CNGR**: 전구체 ↔ 리사이클 폐쇄루프
- **Bamo**: 양극재 ↔ Huayou 전구체
- **Ronbay·Shanshan**: 양극/음극 + 전구체 내재화
- **Redwood·Ascend**: 리사이클 → pCAM/CAM(양극재 성격 병존)
→ 단일 세그먼트 배정 불가 → 복수 태그 필요(결정 5).

## 발견 방식의 한계 (빈도가 못 잡는 것)
1. 빈도가 CATL·BYD·대형 OEM에 쏠려, 켐코·새빗켐·에코프로씨엔지 같은 **한국 도메스틱 상류사**가 실제 중요도보다 과소평가된다.
2. 폐쇄루프 수직통합사는 한 세그먼트로 안 잡혀 단일 목록 대조 시 누락·중복이 동시 발생한다.
3. 검색이 출하량·판매량 위주라 계약·인증·차세대(실리콘 음극·전고체) 등 **미래 수요처·기술 파트너십**은 후행 반영 — 별도 정성 조사 필요.
