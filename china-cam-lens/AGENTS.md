# AGENTS.md — China CAM/AAM Lens 작업 규칙

중국 양극재·음극재 소재사 전문 시장 인텔리전스 서비스. **무엇을** 만드는지는 [PRD.md](PRD.md), **어떤 순서로**는 [plan.md](plan.md). 이 문서는 **어떻게 일할지**만 다룬다. BatteryLens 프레임워크를 계승하며, 아래는 중국 스코프의 델타를 포함한 전체 규칙이다.

## 작업 순서

1. 작업 전 plan.md의 현재 Phase·항목과 완료 기준을 확인한다. Phase를 건너뛰지 않는다.
2. 완료 기준을 스스로 검증한 뒤 완료로 표시한다. 검증 없는 완료는 미완료다.
3. 설계가 PRD와 충돌하면 멈추고 발주자에게 질문한다.
4. plan.md 체크박스를 진행에 맞춰 갱신·커밋한다.

## 불변 규칙

- **저작권**: 기사 본문을 번역·요약용으로 일시 취득하는 것은 허용하되, 처리 후 본문 원문은 DB·로그·파일 어디에도 남기지 않는다. 저장은 제목·출처 링크·발행일·매체명·**자체 한국어 요약**만. 본문 페처는 robots.txt·소스별 정책을 따른다.
- **LLM 중립**: 모든 LLM 호출은 `llm/` 추상화 레이어를 거친다. 프로바이더(기본 Claude, 전환 OpenAI)·모델명은 환경변수로만. **중국어→한국어 번역 품질**이 이 서비스의 핵심 가치이므로, 번역·요약 프롬프트는 소재·화학 전문용어 사전을 주입한다.
- **시크릿**: API 키·마스터키는 환경변수·GitHub Actions secrets로만. 코드·설정·로그·커밋엔 키 이름만.
- **멱등**: 파이프라인은 같은 날짜 재실행 시 중복 행이 생기지 않는다(자연키 upsert).
- **무료 우선**: 유료 소스(Finlight·FinancialFilings China API)는 발주자 승인 없이 붙이지 않는다. MVP는 무료(AKShare·CNINFO·크롤링)로.
- **한국어**: 사용자에게 보이는 모든 텍스트는 한국어. 소스는 중국어(+영문). 코드 식별자·커밋 메시지는 영어.

## 저장소 구조

```
pipeline/      # Python — 수집·정독·번역·요약·리포트 배치
  sources/     # 소스별 1모듈 (akshare, cninfo, sse, hkexnews, ggii, cbea, kr36, cnevpost, gnews_zh)
  fetch/       # 본문 페처 — 중국어 기사 본문 일시 취득(robots 존중), 반환만·영속 저장 안 함
  llm/         # 프로바이더 중립 레이어 + 프롬프트(번역 사전 포함, 코드와 분리된 파일)
web/           # Next.js(TypeScript) — 대시보드·챗·관리자 (한국어 UI)
supabase/      # 마이그레이션 SQL (스키마 단일 출처)
companies.yaml # 중국 셀+소재사 마스터 (부록 A에서 확정, 유형 태그 배열: 셀/양극/음극)
.github/workflows/  # daily.yml, weekly.yml, monthly.yml
```

- 수집기는 **1소스 1모듈**: 한 소스 장애·교체가 다른 소스에 닿지 않게.
- DB 스키마 변경은 `supabase/` 마이그레이션으로만.

## 코딩 규칙

- **파이프라인 = Python, 웹 = TypeScript.** 영역 넘는 혼용 금지.
- 실행·테스트·린트 명령은 `pipeline/pyproject.toml`·`web/package.json` scripts가 단일 출처.
- 외부 데이터(티커 .SZ/.SS/.HK/.BJ, CNINFO 코드, RSS URL, API 필드)는 실측 검증 후 사용. 중국사 사명(중/영/한)은 별칭 테이블로 관리.
- 비공식 소스(AKShare·East Money·Google News zh)는 지수 백오프·캐싱, 실패는 `pipeline_runs` 기록 후 다음 소스로 진행.
- 프롬프트(번역·분류)는 코드와 분리한 파일로 버전 관리 — 번역·분류 품질 개선이 코드 수정 없이 가능해야 한다.
- 비상장 소재사는 재무가 없을 수 있으므로, 재무 부재를 정상 상태로 처리(화면 "재무 미공개").

## 검증

- 파이프라인 변경: 소량 샘플(상장 소재사 2~3개)로 실제 소스 호출 스모크 통과 후 완료. 번역·분류 LLM 단계는 고정 입력 스냅샷 테스트로 회귀 방지 + 한국어 번역 표본을 발주자 검수.
- 웹 변경: `web/` lint·typecheck·build 통과.
- 시크릿 필요한 테스트는 환경변수 부재 시 skip 처리해 CI를 깨뜨리지 않는다.
