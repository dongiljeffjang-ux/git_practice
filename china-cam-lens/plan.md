# plan.md — China CAM/AAM Lens 구현 순서

> 각 Phase는 앞 Phase에 의존한다. 순서대로 진행하고 항목별 **완료 기준**을 충족해야 체크한다. 규칙은 [AGENTS.md](AGENTS.md), 요구사항은 [PRD.md](PRD.md). BatteryLens plan을 계승하되 중국 스택·번역·소재군 세그먼트를 반영했다.

## Phase 0 — 기반 셋업

- [ ] **0.1 저장소 스캐폴드**: `pipeline/`·`web/`·`supabase/` 생성.
  완료 기준: 파이프라인 스모크와 web dev 서버가 로컬에서 뜬다.
- [ ] **0.2 외부 계정·키 준비**: 필요한 키(Supabase, Vercel, AKShare 무료·CNINFO Data Service 조건 확인, Anthropic/OpenAI, Resend)를 `docs/setup.md`로 정리. 유료 소스는 보류.
  완료 기준: 키가 secrets·`.env`에 세팅되어 스모크 통과.
- [x] **0.3 소스 접근 확정**: 검증 완료 → `docs/sources.md`. MVP 무료 스택(AKShare·CNINFO·HKEXnews·36kr·GNews-zh·CnEVPost) 확정, 유료 헤지(Finlight·FinancialFilings·CNINFO API)는 승인 후. 남은 것: CNINFO 공식 API·FinancialFilings 상위 티어 **비용은 계약 전 직접 견적**(도메인 차단으로 미확인).
- [ ] **0.4 DB 스키마 v1**: PRD §7.1 테이블을 마이그레이션으로 생성(소재군 세그먼트 배열 포함).
  완료 기준: 빈 프로젝트에 오류 없이 적용.
- [ ] **0.5 companies.yaml 확정(발견 패스)**: 중국 양극재·음극재 소재사 발견 패스로 목록 도출 → 티커(.SZ/.SS/.HK/.BJ)·CNINFO 코드·소재군 세그먼트(복수)·중/영/한 별칭·상장여부 채움. 비상장사 표시. 발주자 확정.
  완료 기준: 상장 소재사의 티커·코드 실측 검증, 비상장사 표시, 소재군 세그먼트 배정, 발주자 확정.
- [ ] **0.6 LLM 중립 레이어 + 번역 사전**: `pipeline/llm/` 프로바이더 전환 + 소재·화학 전문용어 中→韓 사전을 프롬프트에 주입.
  완료 기준: 같은 번역·분류 호출이 두 프로바이더에서 동작, 전문용어가 사전대로 번역됨.

## Phase 1 — 수집·정독·번역·축적 + 데일리 리포트 + 트렌드 (PRD F1~F5)

- [ ] **1.1 수집기**: akshare(시세·재무) / cninfo·sse·hkexnews(공시) / ggii·cbea·kr36·cnevpost·gnews_zh(뉴스). 1소스 1모듈, 백오프·실패 격리, `pipeline_runs`.
  완료 기준: 상장 소재사 3개 샘플로 전 소스 실데이터 스모크 통과, 임의 1개 실패시켜도 완주.
- [ ] **1.1b 본문 페처**: 중국어 기사 본문 일시 취득, robots·소스별 정책, 실패 시 스니펫 폴백. 본문 영속 저장 안 함을 테스트로 검증.
  완료 기준: 대표 중국 매체 5곳 본문 추출, robots 차단 사이트 스킵, 본문 미저장 검증.
- [ ] **1.2 정제(2단계 + 번역)**: 스니펫 게이트 → 본문 정독 + 中→韓 번역·요약 + 소재군 세그먼트·카테고리·테마·키워드·이벤트·관계. 중복 클러스터링(대표 1건만 페치).
  완료 기준: 실수집 50건 샘플의 번역·분류를 발주자 검수 승인. 전문용어 번역 정확. 스냅샷 테스트.
- [ ] **1.3 일일 워크플로**: `daily.yml` 매일 1회, workflow_dispatch, 멱등.
  완료 기준: 3일 연속 무인 성공, 같은 날 2회 실행 중복 0.
- [ ] **1.4 백필**: 상장 소재사 주가·재무·공시 과거 3년. 뉴스는 런칭일부터.
  완료 기준: 상장 소재사에 3년치 데이터 존재, 표본 대조 일치. 비상장사는 재무 공백 정상 처리.
- [ ] **1.5 데일리 리포트**: 하루 1개, **소재군 세그먼트별 섹션**(동향 요약 + 주요 기사 Top 5 원문 링크) → DB + 이메일. 중요도 스코어링.
  완료 기준: 소재군별로 구성된 리포트가 이메일 도착, 각 세그먼트 동향+Top 5 링크, 본문 미포함.
- [ ] **1.6 최소 웹 + 인증**: OTP + 마스터키 → 리포트 열람.
  완료 기준: 허용 도메인 가입·거부·마스터키 접속 확인.
- [ ] **1.7 품질 튜닝(2주)**: 번역·분류 프롬프트를 발주자 피드백으로 개선.
  완료 기준: 발주자가 "리포트를 매일 실무에 쓸 수 있다" 확인.
- [ ] **1.8 트렌드 테마 + 시드 백필**: 중국 소재 거시 테마(LFP↔삼원계, 고체전해질, 단결정·고전압, 실리콘 침투, 수출규제 등) 승인 → 18개월 seeded 집계.
  완료 기준: 승인 테마 10~20개, 18개월 집계, 발주자 표본 검수.
- [ ] **1.9 트렌드 대시보드(경량)**: 리포트 상단 테마 추이·시점 비교·한 줄 요약·상승 키워드. seeded/measured 구분.
  완료 기준: 두 시점 비교 요약 생성, seeded/measured 구분 표시.

## Phase 2 — 대시보드 (PRD F6)

- [ ] **2.1 회사 페이지**: 프로필 + 시계열 + 이벤트 타임라인 + 주가 이벤트 마커. 회사 선택 UI를 **소재군별 그룹화**. 비상장사는 "재무 미공개" 표시.
  완료 기준: 상장 소재사에서 3년 주가+이벤트 마커, 소재군 그룹 선택, 비상장사 처리 확인.
- [ ] **2.2 비교 화면**: 소재사 2~5개(**소재군 교차 허용**), 공통 축(주가 정규화·타임라인), 전용 지표는 해당 회사만.
  완료 기준: 소재군 다른 회사(예: LFP양극 × 인조흑연음극) 주가 정규화 비교, 한쪽 전용 지표 처리.
- [ ] **2.3 정책·시장 트랙**: 회사 무관 중국 정책·규제·시장 뉴스 타임라인.
  완료 기준: `policy`·`market` 항목이 이 페이지에 시간순 표시.
- [ ] **2.4 관리자 — 업로드/재분류**: 판매량·캐파 업로드, 오분류 수정, 회사 추가/비활성.
  완료 기준: 정상 파일 반입, 오류 행 단위 거부, 수정 즉시 반영.
