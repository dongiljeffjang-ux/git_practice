> **BatteryLens 프레임워크 재사용** — 아키텍처·파이프라인·리포트 구조·트렌드 대시보드·복수 세그먼트·저작권 방침을 그대로 계승하고, 스코프(중국 소재사 한정)·소스(중국 스택)·회사 목록·리포트 세그먼트만 재정의했다.

## 1. 배경과 목표

발주자는 한국 배터리 **양극재·음극재 소재사**의 시장조사 담당자다. 밸류체인 전반을 넓게 보는 것과 별개로, **중국 소재 경쟁사만 깊게 파는 전문 도구**가 필요하다 — 중국이 양극재·음극재 물량의 대부분(음극재 글로벌 97%, LFP 양극 72%+)을 쥐고 있고, 정보의 1차 소스가 중국어라 한국에서 실시간 추적이 어렵기 때문이다.

**목표**: 중국 양극재·음극재 소재사에 대한 **중국어 1차 정보**(현지 언론·公众号·공시·정책)를 자동 수집·번역·정제·축적하고, 회사·소재군별 시계열과 트렌드, 리포트, 챗, 관계도를 얹는다. 범용 배터리 툴이 얕게 훑던 중국 소재 영역을 깊게 판다.

**성격**: 사내 도구. 외부 공개 정보만 사용. 사외 클라우드(Vercel/Supabase) 무료 티어 시작.

## 2. 사용자

BatteryLens와 동일: 일반 사용자(사내 ≤20명, 열람·챗), 관리자 1인(회사·테마 관리, 파일 업로드, 승인, 재생성). 인증도 동일(회사 이메일 OTP + 마스터키). **사용자에게 보이는 텍스트는 한국어**, 소스는 중국어 중심(+영문).

## 3. 범위

### 3.1 추적 대상 — 중국 양극재·음극재 소재사 (핵심 유니버스)

| 소재군(리포트 세그먼트) | 대상 |
|---|---|
| 양극-삼원계(NCM/NCA) | Ronbay, Easpring(当升), Reshine, Bamo(巴莫), XTC(厦钨新能), Shanshan 양극 등 |
| 양극-LFP·LMFP | Hunan Yuneng(裕能), Dynanonic(德方纳米), 등 |
| 음극-인조흑연 | BTR(贝特瑞), Shanshan(杉杉), Putailai(璞泰来), Zhongke Electric(中科电气), Shangtai(尚太), Kaijin(凯金) 등 |
| 음극-실리콘·차세대 | (중국 실리콘 음극 진영 — 발견 패스로 보강) |

- **세그먼트는 소재군 기준**(밸류체인 7분류 아님). 한 회사가 양극·음극·전구체를 겸업하면 **복수 세그먼트 태그**(예: Shanshan = 양극+음극, Ronbay = 양극+전구체).
- 초기 목록은 `companies.yaml`로 관리. 확정 전 발견 패스(중국 소재사 대상)로 도출.

### 3.2 맥락 참조(추적 유니버스는 아니지만 리포트·관계도에 등장)

- **중국 셀 고객**(CATL·BYD·EVE·CALB 등) — 소재사의 수요처로서 계약·인증 맥락에만.
- **전구체·리사이클 상류**(CNGR·Brunp·GEM·Huayou 등) — 소재사와의 수직관계 맥락에만. 다수가 비상장/자회사라 재무는 공백일 수 있음(§9).

### 3.3 범위 외 (명시)

- 비중국 소재사(에코프로비엠·L&F·Umicore·BASF 등) — **이 툴에서는 제외**(범용 BatteryLens가 담당).
- 셀·OEM을 독립 추적 대상으로 삼지 않음(맥락 참조만).
- 전해질·분리막·장비, 광산·제련.
- 유료 데이터 자동 수집(관리자 업로드만), 챗 상시 웹검색(명시 요청만 — F8).

## 4. 데이터 소스 명세 (⚠️ 검증 리서치 결과 반영 대기)

중국 스택으로 전면 교체. 판정·조건은 검증 후 확정. 현재 후보:

| 역할 | 후보 소스 | 비고(검증 전) |
|---|---|---|
| A주 주가·재무 | **AKShare**(오픈소스, East Money·CNINFO aggregation) | 무료·Python. 소재사 상장분 커버 기대. 비공식 차단 리스크 확인 필요 |
| 시세·재무·뉴스 보조 | East Money 东方财富 | 비공식 API, AKShare가 감쌈 |
| 중국 상장사 공시·IR | CNINFO 巨潮资讯 + CNINFO Data Service API | 선전 계열. 사업/분기/임시공시·PDF. API는 인증/유료 조건 확인 |
| 상하이 공시 | SSE(상하이거래소) | 공시·영문 |
| 홍콩·H주 공시 | HKEXnews | 연차·실적발표 |
| 중국 산업 뉴스 | GGII 高工锂电 · 电池中国(cbea) · 36kr RSS · CnEVPost(영문) | GGII API 없음 → 크롤링/公众号(WeWe RSS·RSSHub) 우회 실효성 확인 |
| 중국 금융 뉴스(유료) | Finlight(财新·财联社·东方财富) | 유료 중심 |
| 구조화 공시(유료) | FinancialFilings China API | JSON/MD/PDF, 유료 |
| 뉴스 발견(보조) | Google News RSS zh-CN | 비공식, 피드당 ~100건 |
| 수동 업로드 | 판매량·출하량·캐파(SNE·GGII 리포트) | 비정기, 관리자 업로드 |

**백필**: 상장 소재사 주가·재무·공시는 과거 3년 소급(AKShare/CNINFO). 뉴스 원문은 런칭일부터. 트렌드 시드 18개월(중국어 검색 + 리서치 추정, `data_origin=seeded`).

**언어**: 소스 중국어(+영문) → **한국어 번역·요약**. 번역 품질이 이 툴의 핵심 가치이므로 LLM 요약 단계가 곧 번역 단계다.

## 5. 기능 요구사항 (BatteryLens 계승, 중국 소재 관점 재해석)

- **F1 일일 수집 파이프라인**: GitHub Actions 매일 1회. 중국 소스별 1모듈, 실패 격리·백오프.
- **F2 2단계 정제**: ① 스니펫 게이트(관련성·회사 대략 매핑) → ② 통과분 **본문 정독 + 중국어→한국어 번역·요약** + 소재군 세그먼트·카테고리·테마·키워드·이벤트·관계 추출. 본문 폐기, 요약+링크만 저장(§6.2).
- **F3 회사별 시계열**: 주가·시총, 분기 재무(중국 공시 기준 항목), 판매량·출하량·캐파(수동), 이벤트 타임라인.
- **F4 데일리 리포트**: 하루 1개. **소재군 세그먼트별 섹션**(양극-삼원계 / 양극-LFP / 음극-인조흑연 / 음극-실리콘) = 동향 요약 + 주요 기사 Top 5(클릭→원문). 상단에 트렌드 대시보드.
- **F5 산업 트렌드 대시보드**: 중국 소재 거시 테마(예: LFP↔삼원계 전환, 고체전해질, 단결정·고전압, 실리콘 음극 침투, 반덤핑·수출규제)·키워드 추이, 1y/6m/3m/1m 비교, 시드 백필.
- **F6 대시보드**: 회사 페이지(소재군 그룹 선택), 비교 화면(소재군 교차 허용, 주가 정규화 공통축), 정책·시장 트랙.
- **F7 정기 보고서**: 위클리·먼슬리(HTML→PDF), 반기 초안.
- **F8 인터랙티브 챗**: DB 근거 한정, 명시 요청 시 웹검색.
- **F9 관계도**: 소재사↔셀 고객·전구체 상류 관계(공급계약·JV·지분·인증). LLM 추출 → 관리자 승인.
- **F10 관리자**: 회사·테마 관리, 파일 업로드, 승인 대기열, 재생성, 실행 로그.

## 6. 비기능 요구사항 (BatteryLens 계승)

- **6.1 비용**: 무료 티어 시작. 유료 소스(Finlight·FinancialFilings)는 발주자 승인 후에만. LLM 월 예산 목표는 번역량이 많아 BatteryLens보다 상향 검토.
- **6.2 저작권**: 일시적 정독 허용, **본문 저장 금지**. 저장은 제목·링크·발행일·매체명·자체 한국어 요약. robots·소스별 정책 준수.
- **6.3 LLM 중립**: 단일 추상화 레이어, 환경변수 전환(기본 Claude, OpenAI 전환). **중국어→한국어 번역 품질**이 모델 선택의 핵심 기준.
- **6.4 안정성**: 소스 독립 실패 격리, 비공식 소스(AKShare·East Money·Google News) 백오프·캐싱, 멱등.
- **6.5 언어**: 소스 중국어(+영문), 출력 한국어.

## 7. 아키텍처 (BatteryLens 계승)

```
[GitHub Actions (매일, Python)]
  수집(AKShare 시세·재무 / CNINFO·SSE·HKEXnews 공시 / GGII·电池中国·36kr·CnEVPost·GNews-zh 뉴스)
  → 1차 게이트(스니펫) → 2차 정독(본문 취득 → 中→韓 번역·요약·소재군 태깅·테마·관계, 본문 폐기)
  → Supabase Postgres 저장(집계 갱신) → 데일리 리포트 + 트렌드 데이터 → Resend 이메일

[1회성 트렌드 시드 잡] 중국어 과거검색 + 리서치 → 18개월 집계(seeded)

[Supabase] Postgres + Auth(OTP) + Storage(업로드·PDF)
[Next.js on Vercel] 대시보드·비교·리포트·챗·관리자 (한국어 UI)
```

### 7.1 데이터 모델 (BatteryLens 계승 + 중국 특화)

## 8. 단계별 릴리스 (BatteryLens 계승)

1. **Phase 1**: 중국 소스 수집→2단계 정독(번역 포함)→축적 + 백필 + 데일리 리포트(소재군별) + 트렌드 대시보드 + 최소 인증
2. **Phase 2**: 대시보드(회사·비교·정책 트랙)
3. **Phase 3**: 정기 보고서
4. **Phase 4**: 챗 + 관계도

## 9. 리스크와 대응 (중국 특화 추가)

| 리스크 | 대응 |
|---|---|
| 비공식 중국 소스(AKShare·East Money) 변경·차단 | 실패 격리·백오프·캐싱, 소스별 모듈 분리, 대체 소스 |
| **비상장·소형 소재사 재무 공백** | 상장 대형사만 정량 확보 가능. 비상장(Bamo·Brunp 등)은 뉴스·공시 정성 + 수동 업로드로 보완, 화면에 "재무 미공개" 표시 |
| 중국어 원문 크롤링 robots·ToS | 게이트 통과분만, robots 존중, 公众号는 WeWe RSS 우회 실효성 검증, 실패 시 스니펫 폴백 |
