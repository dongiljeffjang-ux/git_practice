# China Battery Lens

중국 배터리 **소재·셀** 시장 인텔리전스 서비스 (사내 도구). 한국 양극재·음극재 소재사(포스코퓨처엠) 관점에서 중국 경쟁·수요처를 모니터링한다.

이 폴더는 **기획 산출물**이다. 구현은 Codex가 이 문서들을 따라 수행한다.

## 이 서비스가 하는 일 (두 핵심 기능)

1. **산업 동향 모니터링(전체 조망)** — 매일 중국어 언론에서 중국 배터리 소재산업 전체의 큰 그림을 뽑아 보여준다(셀사 포함). 오늘의 동향 요약 + 테마·키워드 추이(1y/6m/3m/1m 비교) + 유형별 주요 기사 피드(원문 링크).
2. **회사별 분석·비교** — 셀사 + 양극/음극 소재사를 회사별 시계열(주가·재무·이벤트) 분석하고 회사끼리 비교(유형 교차 허용).

## 절대 규칙 (AGENTS.md §불변 규칙 요약)

- **저작권**: 기사 본문을 번역·요약용으로 일시 취득은 허용하되, 본문 원문은 어디에도 저장하지 않는다. 저장은 제목·링크·발행일·매체·자체 한국어 요약만.
- **한국어 출력**: 소스는 중국어(+영문), 사용자에게 보이는 텍스트는 전부 한국어. 中→韓 **번역 품질이 핵심 가치**.
- **LLM 중립**: 프로바이더(기본 Claude, 전환 OpenAI)·모델명은 환경변수로만.
- **무료 우선**: 유료 소스(Finlight·FinancialFilings·CNINFO 공식 API)는 발주자 승인 없이 붙이지 않는다. MVP는 무료 스택(AKShare·CNINFO·HKEXnews·36kr·GNews-zh·CnEVPost).
- **2단계 정독**: 스니펫 게이트 → 통과분만 본문 정독(+번역). 비용·부하 통제.
