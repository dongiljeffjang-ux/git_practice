## 1. 배경과 목표

발주자는 한국 배터리 **양극재·음극재 소재사**의 시장조사 담당자다. 중국이 소재 물량의 대부분(음극재 글로벌 97%, LFP 양극 72%+)을 쥐고 있고 그 수요처인 셀 시장도 중국이 절반 이상인데, 정보의 1차 소스가 중국어라 한국에서 실시간 추적이 어렵다. **중국 배터리 소재·셀 영역만 깊게 파는 전문 도구**가 필요하다.

**목표**: 중국어 1차 정보(현지 언론·公众号·공시)를 자동 수집·번역·정제하고, 딱 두 가지를 잘한다 —

1. **산업 동향 모니터링(전체 조망)**: 매일 언론에서 중국 배터리 **소재산업 전체의 큰 그림**을 뽑아 보여준다. 셀사(CATL 등)의 움직임까지 포함해, 오늘 업계에서 무슨 일이 있었고 흐름이 어디로 가는지 한눈에.
2. **회사별 분석·비교**: **셀사와 양극/음극 소재사**를 회사별로 시계열(주가·재무·이벤트) 분석하고, 회사끼리 비교한다.

범용 배터리 툴이 얕게 훑던 중국 영역을 깊게 파는 것이 핵심이다. **형식적 정기 보고서가 목적이 아니라, 매일의 모니터링과 회사 분석 도구**다.

**성격**: 사내 도구. 외부 공개 정보만 사용. 사외 클라우드(Vercel/Supabase) 무료 티어 시작.

### 1.1 차별점 — "공시만 보는 자료"와 무엇이 다른가

공시(CNINFO/HKEX) 기반 분석은 정형·신뢰도 높지만 **후행적이고, 이미 상품화돼 있고, 중국 핵심 플레이어 상당수가 비상장이라 아예 안 잡힌다.** 이 툴은 공시를 정량 백본으로 쓰되, 그 위에 **비정형 중국어 선행지표 레이어**(언론·公众号·업계지·정책)를 얹어 4가지로 차별화한다:

1. **비상장 다수를 커버** — Brunp·Bamo·Reshine·Kaijin·Hithium·SVOLT 등은 공시가 없다. 뉴스·公众号가 이들을 추적하는 **유일한 수단**이며, 중국 소재 핵심의 절반이 여기 걸린다(구조적 해자).
2. **선행 지표** — 증설 계획·고객 인증(认证)·파일럿 라인·가격 움직임·정책 시그널은 공시(분기 후행)보다 **몇 달 앞서** 뜬다. 시장조사의 본질인 "예측"은 공시만으론 불가능하다.
3. **왜/맥락** — 공시는 "매출 -20%"만, 업계지·公众号는 "왜"(LFP 치킨게임, 고객의 삼원계→LFP 전환, 가동률 급락)를 준다. 분석적 가치는 이 서사에 있다.
4. **중국어 접근 + 한국어 번역** — 정형 공시는 영문 정형 피드로 유통되지만, 번역 안 된 중국 업계 담론은 아니다. 그 원재료 자체가 차별화 지점이다.

**포지셔닝: 공시(정량 백본) + 비정형 중국어 선행지표 레이어의 융합.** 대신 뉴스 레이어의 노이즈는 2단계 정독·출처표시·신뢰도 관리로 상쇄한다.

## 2. 사용자

BatteryLens와 동일: 일반 사용자(사내 ≤20명, 열람·챗), 관리자 1인(회사·테마 관리, 파일 업로드, 승인, 재생성). 인증도 동일(회사 이메일 OTP + 마스터키). **사용자에게 보이는 텍스트는 한국어**, 소스는 중국어 중심(+영문).

## 3. 범위

두 기능의 범위가 **다르다**. 산업 조망(기능 1)은 넓게, 회사 분석(기능 2)은 좁게.

### 3.1 회사 분석·비교 대상 (기능 2의 추적 유니버스)

시계열·비교의 실제 대상 = **중국 셀사 + 중국 양극/음극 소재사**. 이들만 회사 페이지·비교에 오른다.

| 구분 | 대상(예시, 발견 패스로 확정) |
|---|---|
| 셀사 | CATL, BYD, EVE Energy, CALB, Gotion, Sunwoda, Hithium, REPT, SVOLT 등 |
| 양극재(삼원계) | Ronbay(容百), Easpring(当升), Reshine, Bamo(巴莫), XTC(厦钨新能) 등 |
| 양극재(LFP·LMFP) | Hunan Yuneng(裕能), Dynanonic(德方纳米) 등 |
| 음극재(인조흑연) | BTR(贝特瑞), Shanshan(杉杉), Putailai(璞泰来), Zhongke Electric(中科电气), Shangtai(尚太), Kaijin(凯金) 등 |
| 음극재(실리콘·차세대) | 중국 실리콘 음극 진영 — 발견 패스로 보강 |

- 회사에 **유형 태그(셀 / 양극 / 음극)를 복수 허용**(겸업사, 예: Shanshan = 양극+음극). 회사 그룹 선택·비교에서 유형별로 묶인다.
- 초기 목록은 `companies.yaml`. 발견 패스(중국 셀+소재사 대상)로 도출.
- BTR·Shanshan 등 상장사는 AKShare·CNINFO로 시세·재무 확보. 비상장(Bamo 등)은 재무 공백 → "재무 미공개"(§9).

### 3.2 산업 조망 범위 (기능 1의 모니터링 대상 — 더 넓다)

매일 언론 모니터링은 **중국 배터리 소재산업 전반**을 조망한다: 양극·음극 소재를 중심으로, **셀사(CATL 등)의 움직임**과 전구체·전해질·분리막 등 **인접 소재의 뉴스도 맥락으로 포착**해 "업계 전체 그림"을 만든다. (단, 이 인접 소재사들은 §3.1의 회사 분석 대상은 아니다 — 뉴스 조망에만 등장.)

### 3.3 범위 외 (명시)

- 비중국 소재사·셀사(에코프로비엠·L&F·LGES 등) — 이 툴에서는 제외(범용 BatteryLens가 담당).
- OEM(완성차)을 추적 대상으로 삼지 않음(뉴스에 나오면 맥락으로만).
- 광산·제련, 장비.
- 인접 소재(전구체·전해질·분리막)를 **회사 분석 대상으로는** 삼지 않음(산업 조망 뉴스에만).
- 유료 데이터 자동 수집(관리자 업로드만), 챗 상시 웹검색(명시 요청만).

### 무료 스택 밖 → 수동 업로드·정성 처리

- **비상장 소재사 재무** (Brunp·Bamo 등) — 개별 공시 없음, 모회사 연결 주석만. 화면 "재무 미공개".
- **산업 출하량·점유율·가동률 원데이터** (GGII·SNE 유료 리포트) — API 없음 → 관리자 파일 업로드.

**백필**: 상장 소재사 주가·재무·공시 과거 3년(AKShare/CNINFO). 뉴스 원문은 런칭일부터. 트렌드 시드 18개월(중국어 검색+리서치, `data_origin=seeded`).

**언어**: 소스 중국어(+영문) → **한국어 번역·요약**. 번역 품질이 핵심 가치이므로 LLM 요약 단계가 곧 번역 단계다.

**robots/ToS**: CNINFO·HKEXnews·东方财富는 비문서화 크롤링이 광범위(AKShare 전제)하나 상업 서비스화 시 **대량 재배포엔 법무 리뷰 권장**. 公众号는 반크롤링으로 우회 불안정 → 보조로만.

## 5. 기능 요구사항

파이프라인(F1·F2) 위에 **두 핵심 기능**(F3·F4·F5)을 얹는다. 챗·관계도·정기보고서는 후순위(§5.9).

### 파이프라인 (기반)

- **F1 일일 수집 파이프라인**: GitHub Actions 매일 1회. 중국 소스별 1모듈(AKShare·CNINFO·HKEXnews·36kr·GNews-zh·CnEVPost·GGII), 실패 격리·백오프.
- **F2 2단계 정제 + 번역**: ① 스니펫 게이트(관련성·회사 대략 매핑) → ② 통과분 **본문 정독 + 중국어→한국어 번역·요약** + 회사·유형 태깅·카테고리·테마·키워드·이벤트 추출. 본문 폐기, 한국어 요약+링크만 저장(§6.2).
  - **시장/기술 축 태깅**: 각 이벤트에 **시장(market) / 기술(technology) 축을 복수 태그**(배타 아님 — 예: "차세대 라인 증설"=시장+기술). 8분류에서 자동 매핑(시장=수주·증설·실적·시장동향·정책 / 기술=기술R&D·기술제휴), 애매하면 LLM 판정. 이 축이 아래 F3·F4·F5의 시장/기술 분리를 구동한다.

### 기능 1 — 산업 동향 모니터링 (전체 조망)

- **F3 산업 조망 뷰**: 매일 언론에서 뽑은 **중국 배터리 소재산업 전체의 큰 그림**(셀사 포함). "형식적 리포트"가 아니라 **모니터링 뷰**다:
  - **오늘의 동향 요약**: 업계 전반에서 오늘 벌어진 일을 LLM이 흐름 중심으로 서술(양극·음극·셀 + 인접 소재 맥락).
  - **거시 테마·키워드 추이**: 중국 소재 테마(LFP↔삼원계 전환, 고체전해질, 단결정·고전압, 실리콘 음극 침투, 반덤핑·수출규제 등)·키워드의 강도 변화를 **1년/6개월/3개월/1개월 전과 비교**해 흐름을 보여줌(시드 백필 18개월, seeded/measured 구분).
  - **시장 모멘텀 / 기술 모멘텀 분리**: 산업 전체의 흐름을 **시장 축과 기술 축 2개 선**으로 나눠 보여준다(F2 시장/기술 태그 기반). 예: 시장은 가격전쟁으로 하강하는데 기술(고체전해질·나트륨)은 상승 — 이 갭이 곧 산업 시그널이며, 기술 축은 시장을 1~3년 선행한다.
  - **주요 기사 피드**: 오늘의 핵심 기사를 유형(셀/양극/음극/정책·시장)별로 묶어 제목·한 줄 요약·**원문 링크**(클릭→원문, 본문 미저장)로. 중요도 스코어링(이벤트성·영향도 + 재보도 클러스터 크기).
- 대시보드 첫 화면 + 구독자 이메일(요약·링크만).

### 기능 2 — 회사별 분석·비교

- **F4 회사 페이지 (시계열)**: §3.1 유니버스(셀사·양극/음극 소재사)의 회사별 —
  - 프로필, **수치 시계열**(주가·시총, 분기 재무[중국 공시 항목], 판매량·출하량·캐파[수동]), **이벤트 타임라인**, 주가 차트 위 이벤트 마커 오버레이.
  - **이벤트 타임라인을 시장/기술 2개 스윔레인으로 분리**: 위 레인=시장(수주·증설·실적·가격), 아래 레인=기술(R&D·차세대·인증). 한 회사의 "상업적 위치"와 "기술 궤적"을 나란히 읽어 궤적 유형(범용 캐시카우 / 기술 피벗 / 양쪽 하락)을 판별. 시장 레인은 정량 시계열도 겹치고, 기술 레인은 마일스톤 이벤트 중심(데이터가 얇으므로). 각 이벤트는 복수 축이면 양쪽에 표시.
  - 회사 선택 UI는 **유형별 그룹화**(셀 / 양극 / 음극). 비상장사는 "재무 미공개" 표시.
- **F5 회사간 비교**: 회사 2~5개 선택 → 수치 시계열 겹쳐 표시 + 이벤트 타임라인 나란히.
  - **유형 교차 비교 허용**(예: 셀사 × 양극재사). 공통 축(**주가 정규화 수익률**, 이벤트 타임라인)을 기본으로, 일부 회사에만 있는 지표(출하량·캐파 등)는 해당 회사에만.
  - **시장/기술 필터**: 비교 시 이벤트를 시장 축·기술 축으로 필터링해, "누가 시장에서 앞서나" vs "누가 기술에서 앞서나"를 따로 볼 수 있다.

### 공통

- **F6 인증·접근**: 회사 이메일 OTP + 마스터키. 로그인/마스터키 세션 필수.
- **F7 관리자**: 회사·테마 관리, 판매량·캐파 파일 업로드(스키마 검증), 테마 후보 승인, 실행 로그 조회.

### 5.9 후순위 (MVP 이후 검토 — 지금 확정 아님)

- **인터랙티브 챗**(DB 근거 한정, 명시 요청 시 웹검색), **회사 관계도**(소재사↔셀 관계 LLM 추출+승인), **정기 보고서**(위클리·먼슬리 PDF). 발주자가 두 핵심 기능을 검증한 뒤 필요하면 추가.

## 6. 비기능 요구사항 (BatteryLens 계승)

- **6.1 비용**: 무료 티어 시작. 유료 소스(Finlight·FinancialFilings)는 발주자 승인 후에만. LLM 월 예산 목표는 번역량이 많아 BatteryLens보다 상향 검토.
- **6.2 저작권**: 일시적 정독 허용, **본문 저장 금지**. 저장은 제목·링크·발행일·매체명·자체 한국어 요약. robots·소스별 정책 준수.
- **6.3 LLM 중립**: 단일 추상화 레이어, 환경변수 전환(기본 Claude, OpenAI 전환). **중국어→한국어 번역 품질**이 모델 선택의 핵심 기준.
- **6.4 안정성**: 소스 독립 실패 격리, 비공식 소스(AKShare·East Money·Google News) 백오프·캐싱, 멱등.
- **6.5 언어**: 소스 중국어(+영문), 출력 한국어.

## 8. 단계별 릴리스

1. **Phase 1**: 중국 소스 수집→2단계 정독(번역 포함)→축적 + 백필 + **기능 1(산업 동향 모니터링/조망)** + 최소 인증
